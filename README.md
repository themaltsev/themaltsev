## 🔐 M4PROXY / M4 VPN

### Telegram-сервис автоматизации VPN

🤖 https://t.me/m4vpnbot

Собственный сервис автоматизированной выдачи VPN-конфигураций.

Бот управляет жизненным циклом подписки пользователя — от регистрации и тестового периода до выдачи конфигурации и продления доступа.

### Технологии и инфраструктура

Используются:

- `WireGuard`;
- `Xray`;
- `VLESS`;
- `REALITY`;
- Linux VPS;
- несколько серверных локаций;
- Telegram Bot API;
- автоматизированная генерация конфигураций.

### Возможности

- 🔑 автоматическая выдача VPN-доступа;
- 🆓 пробный период;
- 📆 управление сроком подписки;
- 🌍 выбор серверных локаций;
- 📱 работа на нескольких устройствах;
- 🔀 Split VPN;
- 🌐 Full VPN;
- ⚙️ автоматизированное управление пользователями;
- 📊 контроль активных подписок;
- 🔐 генерация индивидуальных конфигураций.

В Split-режиме можно направлять через VPN только определённые сервисы, оставляя остальной трафик напрямую.

Проект сочетает backend-разработку, Telegram Bot API, Linux-администрирование и сетевую инфраструктуру.

## 🎵 M4MUZBOT

### Telegram-бот для работы с музыкой

🤖 https://t.me/m4muzbot

Один из моих крупных Telegram-проектов.

Бот объединяет поиск, получение и обработку музыкального контента непосредственно внутри Telegram.

### Возможности

#### 🔎 Поиск музыки

Пользователь вводит название композиции, после чего бот предлагает найденные варианты.

Можно выбрать необходимый трек и получить его в формате `.mp3`.

#### 🎧 Поиск похожей музыки

Можно отправить команду ответом на существующий трек и найти похожие композиции.

#### ☁️ SoundCloud

Бот умеет работать со ссылками SoundCloud и получать информацию о композициях.

#### ✂️ Работа с аудио

Реализована обработка треков непосредственно через Telegram.

Например, можно указать:

`30@@21`

где:

- `30` — секунда начала;
- `21` — продолжительность результата.

Это позволяет быстро подготовить необходимый фрагмент композиции, например для рингтона или уведомления.

#### 🎙 Работа с голосовыми сообщениями

Бот также умеет обрабатывать голосовые сообщения и применять различные варианты изменения голоса.

Проект включает работу с:

`Telegram Bot API` · `Audio Processing` · `External APIs` · `Python` · `Backend Automation`
